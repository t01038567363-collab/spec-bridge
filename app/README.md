# Spec Bridge 앱 (MVP 시연용)

TRD v3(`TRD.md`) + 프로토타입(`spec_bridge.html`) + TRD v2.0 PDF를 하나로 합친 **클라이언트 전용 웹앱**입니다. 빌드·서버 없이 `index.html`을 브라우저로 열면 됩니다.

## 범위: 시연(MVP) vs 향후
| 구분 | MVP(이 앱) | 향후 서버 단계 |
|---|---|---|
| API | TRD §3의 A1~A10을 **브라우저 안**(`js/api.js`)에서 동일한 경로·상태코드·오류 코드로 구현. UI도 이 API를 통해 판정 | FastAPI로 같은 계약 구현(UI·테스트 재사용) |
| 저장 | 세션을 메모리에만 보관(TTL 24시간), 판정 직후 UI가 세션 삭제 | SQLite, 보존·삭제 정책 |
| 토큰 | 해시만 보관(비암호학적 cyrb53, 시연용) | SHA-256 이상, 전송 구간 TLS |
| LLM | `llm` 훅만 제공, 미설정 시 템플릿(모델 미정) | 모델 확정·연동 |
| 규격 근거 | 후보값(원문 대조 0/10) | 원문 대조 후 `verified` |

## 구성
- `index.html` / `js/app.js` — 4단계 UI, TXT·JSON·복사 내보내기
- `js/data.js` — 기준 데이터: 문서 12항목, 수치 체크리스트 Q01~Q10, 샘플 답변·문서
- `js/engine.js` — 결정적 규칙 엔진, 초안 생성기(템플릿 + 선택적 LLM 훅), 금지 표현 필터
- `js/api.js` — REST 계약 구현(A1 규격, A2 문항, A3 세션·Idempotency-Key, A4 답변, A5 평가, A6 결과, A7 초안, A8 내보내기, A9 삭제, A10 고지), 표준 오류 응답, 상태 전이, 429 한도(5회/10분), 초안 25 s 타임아웃
- `tests.html` / `js/tests.js` — 단위·API 테스트 38건(브라우저에서 `tests.html` 열기)

## 두 가지 검사
1. **A. 문서 12항목**: 업로드 문서의 키워드 3개 이상 충족 / 1~2개 보완 / 0개 누락. 가중치 합(105)을 100점으로 정규화. 근거가 없으면 판정을 만들지 않고 누락 처리.
2. **B. 수치 10문항**: 값·단위·증빙을 규칙으로 대조해 충족 / 미흡 / 확인 필요 판정(API A3→A4→A5→A7→A9). AI는 판정에 관여하지 않고 초안 문장만 만듭니다.

## 정책 모드
- `demo`: 후보 기준값으로 시연 판정(“원문 대조 전” 표기). 기업 A 기본 입력 → 충족 6 · 미흡 2 · 확인 필요 2
- `strict`: `source_status: 'unverified'` 문항은 전부 확인 필요
- 원문 대조 후 `js/data.js`의 해당 문항 `source`에 실제 조항·쪽수를 넣고 `source_status`를 `'verified'`로 바꾸면 strict에서도 판정됩니다.

## 테스트 실행 기록
`tests.html`을 열어 확인하거나 헤드리스 Edge로 실행: `msedge --headless=new --dump-dom file:///…/app/tests.html`

| 일자 | 환경 | 결과 |
|---|---|---|
| 2026-11-27 | Edge(헤드리스), Windows | **38/38 통과** (엔진 27 + API 11, TRD TC-09·11·13·14·15·19·22·26·27 대응) |
| 2026-11-27 | 화면 흐름(샘플 문서→검사→리포트) 스크립트 | 충족 6 / 미흡 2 / 확인 필요 2, 초안 생성 확인 |

TRD의 TC-01~30 중 위에 대응하지 않는 항목(실제 SQLite 저장, 서버 로그 파일 등)은 서버 구현이 없어 **미실행**입니다.

## 한계
- 규격 조항·쪽수와 Q01~Q03 값은 **미확정(가정)** 입니다. 공식 인증·심사가 아닙니다. 원문 대조 0/10.
- 실제 FastAPI·DB·LLM 호출은 포함하지 않습니다.
- 민감어 검사는 작은 고정 사전이라 보조 방어선일 뿐입니다. 가상 데이터만 입력하세요.
- PDF 읽기는 PDF.js CDN을 사용하며 오프라인이면 파일명만 사용합니다. 스캔 PDF는 텍스트를 읽지 못합니다.

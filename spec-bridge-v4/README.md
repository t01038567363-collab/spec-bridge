# 스펙 브릿지 (Spec Bridge) v4 — 최종 실행 대상

국방 규격서의 요구사항과 기업 제출 자료를 **문장 단위로 대조**해 충족 / 보완 필요 / 누락을 판정하는 사전 점검 도구입니다. 점수(가중치)는 쓰지 않고, 규격 원문 ↔ 기업 자료 근거 문장을 항상 함께 보여 줍니다.

> ⚠ 공식 적합 판정이 아닌 **사전 점검 보조 도구**입니다. 군사기밀·개인정보·영업비밀 자료는 올리지 마세요. 파일은 브라우저 안에서만 처리되며 서버로 전송되지 않습니다(서버·로그인 없음).
> 저장소의 `app/`은 이전 별도 구현이며, **최종 버전은 이 폴더(`spec-bridge-v4/`)** 입니다.

## 실행 방법
1. 폴더를 내려받습니다(인터넷 불필요, 설치 불필요).
2. `index.html`을 Chrome / Edge / Firefox 중 하나로 더블클릭해 엽니다.
3. 1단계에서 **기업 / 국방** 선택 → 2단계에서 규격서와 기업 자료 업로드(또는 `+ 샘플` 버튼) → 3단계 **검사 실행** → 4단계 리포트(TXT/JSON 내보내기).

지원 파일: 텍스트 PDF, TXT/MD/CSV/JSON. 스캔 PDF·DOC·XLS·HWP는 텍스트를 추출하지 못하므로 변환 후 올려야 합니다.

## 구성 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 진입점(4단계 화면) |
| `app.js` | UI + 요구사항 추출·대조·판정 로직 |
| `criteria.js` | 심사 항목 세트: 기업 21개 / 국방 47개 (`항목나누기.docx` 기준) |
| `styles.css` | 스타일 |
| `vendor/` | pdf.js 3.11.174 (오프라인 PDF 파싱) |
| `tests.html` | 판정 엔진 테스트 |

## 판정 규칙
- **누락**: 규격 요구문과 연관된 기업 문장이 없음(연관도 < 기준값, 기본 0.40, 화면에서 조정).
- **보완 필요**: 연관 문장은 있으나 규격이 명시한 표준 번호가 없거나, 수치(이상/이하/±/동일)를 만족하지 않거나 수치가 없음.
- **충족**: 연관 문장이 있고 표준·수치가 모두 확인됨(서술형은 "정량 비교 없음" 표시).
- 항목 판정: 소속 요구가 모두 충족 → 충족, 모두 누락 → 누락, 그 외 보완 필요, 요구 없음 → 판정 제외.

## 한계
- 키워드·수치 기반 비교이며 의미 이해가 아닙니다. 연관도 기준값에 따라 결과가 달라집니다.
- 국방 추가 19개 영역은 실무 영역 정리이며 기품원 공식 조항 원문이 아닙니다. 공식 대조는 KDS STD-0005-1 및 최신 심사기준표가 필요합니다.
- 항목 분류(키워드)는 규격 원문과 대조 검증되지 않았습니다.
